# 岡ゼミ版について（本家との違い）

このリポジトリは [Beko6648/AI_StackChan_Ex](https://github.com/Beko6648/AI_StackChan_Ex) を
**M5Stackchan（M5Stack CoreS3）+ Gemini Live** で、**授業で初学者が使えるように**修正したものです。
ライセンスは元と同じ MIT です（`LICENSE` を参照）。

## なぜ本家をそのまま使わないのか

本家は M5Stack Core2 を主な対象としているため、**CoreS3 で使うと不具合が同時に発生します。**
授業時間内に自力で原因にたどり着くのは困難なため、修正済みのものを配布します。

### 動かすために直したこと

| 修正した内容 | 本家のままだと起きること |
|---|---|
| M5Unified を 0.2.15、M5GFX を 0.2.22 に固定（GitHubのタグを直接指定） | **画面が極端に暗い・タッチが効かない・首が動かない**が同時に発生 |
| 書き込み速度を 1500000 → 460800 に変更 | 書き込み中に**本体が起動しなくなる**（実際に発生） |
| 音声再生のチャンネルを 0 に固定 | AIの声が**早口になり、絶えず途切れる** |
| 音声バッファを 2枚 → 3枚 に変更 | 同上（チャンネル固定と両方必要） |
| Gemini Live の接続方式を修正 | 接続直後に切断される／返事が返らない |
| 画面表示を日本語化、タッチ操作を改善 | 英語表示のまま。発話中に触ると**本体が固まる** |
| キャラクター設定の読み込みを有効化 | 性格設定ファイルが一切反映されない |

> 特に上の3つは、**症状から原因を推測することがほぼ不可能**です。
> 画面が暗いのとタッチが効かないのが「同じ1つの原因」だとは、まず気づけません。

### 授業で使いやすくするために変えたこと

| 変更 | ねらい |
|---|---|
| **SDカードを使わない**（設定を本体の内蔵メモリに直接書き込む） | SDの準備・抜き差し・文字コードのトラブルをなくす。設定がパソコン上にあるので、**AIに直接書き換えてもらえる** |
| **返事ができないとき、画面にエラーを表示**（悲しい顔＋吹き出し） | 初学者が「何かが起きた」と分かるようにする |
| 標準の性格を **`basic`（ふつうに会話するだけ）** に | オープンキャンパス用の性格ではなく、素直なものから始める |
| 性格ファイルが見つからなくても**落ちない**ように | 名前を1文字間違えただけで本体が再起動を繰り返していた |
| テザリングが切れても、**戻せば自動でつなぎ直す**ように | 以前は一度切れると電源を入れ直すまでつながらなかった |

## 設定ファイルの場所

設定はすべて **`firmware/data/`** にあります。SDカードは使いません。

```
firmware/data/
├─ SC_SecConfig.yaml.example   ← ひな形。コピーして SC_SecConfig.yaml を作る
├─ SC_ExConfig.yaml            ← どのAI・どの性格を使うか
├─ SC_BasicConfig.yaml         ← 首の設定
└─ characters/
     ├─ basic.yaml             ← 標準の性格
     ├─ okazemi.yaml           ← 見本
     └─ uranai.yaml            ← 見本
```

本体への書き込みは**2段階**です。

| 順番 | 内容 | VSCode（PlatformIO）のボタン | コマンド |
|---|---|---|---|
| ① | 設定ファイル | Platform → **Upload Filesystem Image** | `pio run -t uploadfs` |
| ② | プログラム | General → **Upload** | `pio run -t upload` |

設定だけ変えたときは**①だけ**（約35秒）で反映されます。

## APIキーとWi-Fiパスワードについて

`firmware/data/SC_SecConfig.yaml` には個人のAPIキーとWi-Fiパスワードを書きます。
このファイルは `.gitignore` で除外されており、**GitHubには上がりません。**

配布されているのは中身が伏せ字になった `SC_SecConfig.yaml.example` です。
これをコピーして `SC_SecConfig.yaml` にリネームし、各自の値を入れて使ってください。

> **⚠️ フォルダごとzipにして人に送ると、このファイルも一緒に送られてしまいます。**
> 人に渡すときは `SC_SecConfig.yaml` を必ず除いてください。

## 主な変更ファイル

| ファイル | 内容 |
|---|---|
| `firmware/platformio.ini` | ライブラリのバージョン固定、書き込み速度、SDを使わない指定（`-DCONFIG_FROM_SPIFFS`） |

| `firmware/src/llm/RealtimeLLMBase.cpp` / `.h` | 音声再生（チャンネル・バッファ）、エラー表示 |
| `firmware/src/llm/Gemini/GeminiLive.cpp` | Gemini Live との通信、エラーの検出 |
| `firmware/src/mod/AiStackChan/RealtimeAiMod.cpp` | 画面表示・タッチ操作・表情 |
| `firmware/data/` | 設定ファイルと性格ファイル |
| `my_script/patch_websockets_close_log.ps1` | 切断理由をログに出すためのパッチ（初回ビルド後に実行） |

## AIコーディングエージェントで作業する場合

リポジトリ直下の **`AGENTS.md`** に、岡ゼミ版固有の制約をまとめてあります。
Codex などは、このファイルを自動で読み込みます。

- **触ってはいけない設定**（ライブラリのバージョン、書き込み速度、Gemini への送信形式、音声再生、SDを使わない指定）
- **不具合調査の手順**（まず無料枠を確認する。症状からコードを推測しない）
- ビルド・書き込みコマンド、シリアルログの読み方

`firmware/AGENTS.md` は本家の作者によるコーディング規約です。両方が読まれます。
